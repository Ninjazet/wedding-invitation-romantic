### 🎨 Personalización

#### Cambiar Colores del Amor
Edita las variables CSS en `styles.css`:
```css
:root {
    --rosa-suave: #f8bbd9;
    --rosa-intenso: #e91e63;
    --lavanda: #e1bee7;
    /* ... más colores románticos */
}
```

#### Actualizar Historia de Amor
Modifica la timeline en `index.html` con vuestra historia única.

#### Personalizar Efectos
Ajusta las animaciones y partículas en `script.js`.
